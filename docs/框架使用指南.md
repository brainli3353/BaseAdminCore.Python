# 框架使用指南

## 新增一个业务模块（四步）

1. 实体：继承 `EntityTenant`（或 `EntityTenantBaseData` 需要机构数据权限），表名/列名显式。
2. 服务：`src/core/services/<域>.py`，注入 `AsyncSession`，用 `Repository(session, Entity)`。
3. 路由：`src/web/api/<域>.py`，`APIRouter`，`UserDep` 取当前用户，`success(...)` 返回；在 `router.py` include。
4. 菜单/按钮：新增菜单种子（Type=2 菜单 / 3 按钮，Permission=路由去掉 `/api/`）。

## 登录

- `POST /api/auth/login`：一阶段，返回 `{challengeId, bindRequired, secret?, otpauthUri?}`。
- `POST /api/auth/login/otp`：二阶段，返回 token（头 `X-Refresh-Token` / `X-Password-Expired`）。
- 响应头 `X-Refresh-Token` 为长时效 refresh token，access 过期可直接切换使用。

## 当前用户

- `src.core.db.context.get_current_user()` / `is_super_admin()` / `ensure_user()`。
- 路由用 `UserDep` 注入。

## 缓存

- `get_cache_service()`；键前缀见 `CacheConst`。

## 定时任务

- 在 `src/core/job/scheduler.py` 用 `@register_job("name")` 注册协程；`sys_job_detail` 配置间隔/启用。

## 实时推送

- 后端 `publish_event(kind, payload)`；前端 `web/src/utils/realtime.ts` 订阅。

## 前端

```powershell
cd web; pnpm install; pnpm dev   # :5173 代理 /api → :5090
cd web; pnpm build               # 产物 web/dist，后端同源托管
```
