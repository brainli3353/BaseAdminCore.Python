# 框架索引

## 启动装配（src/web/app.py）

1. `init_schema`：集群锁内建表 + 增量种子（`sys_startup_schema`，三态）。
2. `ensure_worker_id`：雪花 WorkerId 占用登记（`sys_worker_id:{id}`，5min）。
3. `init_realtime`：事件总线 + WebSocket 管理器（`/ws`）。
4. `JobScheduler`：后台定时任务调度（5s 轮询）。
5. 中间件：TraceId → Permission（按钮权限）→ Exception → 路由。
6. 同源托管 `web/dist`（SPA 回退），`/uploads` 静态，`/health`、`/health/live`。

## 目录落点

| 目录 | 职责 |
|---|---|
| `src/core/entities` | 全部实体（表名/列名 PascalCase，主键 `id`） |
| `src/core/db` | 基类/会话/仓储/审计/过滤器/建表/种子执行 |
| `src/core/services` | 业务服务（按域） |
| `src/core/security` | PBKDF2/AES/OTP/UserManager/数据权限 |
| `src/core/job` | 定时任务调度 |
| `src/core/seeds` | 增量种子 |
| `src/web/api` | API 路由（按域） |
| `web/` | Vue3 前端 |

## 关键机制

- 统一响应：HTTP 恒 200，体 `{code, errCode, msg, data}`；long → string。
- 配置链：`.env` / 环境变量（双下划线嵌套）。
- 缓存：`Cache:Type=Redis` 且连接串非空用 Redis，否则 Memory。
- 权限：路由路径派生权限键（`/api/sysUser/page` → `sysUser/page`），白名单外逐请求校验；超管穿透。
- 数据权限：`DataScope` 1 全部 / 2 本部门及以下 / 3 本部门 / 4 仅本人 / 5 自定义，读侧自动过滤，空集 fail-closed。
- 字段权限：受管表（`sys_table_field_scope`）按角色列白名单在响应出口裁剪（`sysUser/page`、`sysRole/page`）。
- 实时：`/ws?token=`，消息 `{kind, data}`（onlineUserList / force_offline / public_notice / receive_message）。

## 常量表
